## 运行方式

### 方式一：双击打开（最简单，推荐给普通用户）

解压后直接双击 `Agent学习资源库-单文件版.html`，浏览器打开即可阅读。
该文件是自包含单文件（样式、脚本和图片全部内嵌），**完全离线可用**，不需要服务器、不需要安装任何软件。

### 方式二：本地服务器（推荐，效果与方式一相同但更稳）

解压后在终端进入 `web/dist` 目录，任选一种命令启动：

```bash
# Python 3（macOS / Linux / Windows 通用）
python3 -m http.server 8080

# Node.js
npx serve .
```

然后浏览器打开 http://localhost:8080 即可阅读（方式一不受此限制，直接双击即可）。

### 方式三：部署到任意静态托管

把 `web/dist` 整个目录上传到 GitHub Pages / Vercel / 对象存储等任意静态托管即可，无需任何服务器端配置（产物使用相对路径，支持子路径部署）。

## 常见问题

**双击单文件版打不开 / 白屏？**
请使用现代浏览器（Chrome / Edge / Safari / Firefox 最新版）。若已打开过旧版本，先清一下该页面的缓存（或换个浏览器）再试。

**为什么单文件版有 6 MB？**
全部 5 本书的正文、Mermaid 渲染引擎与图片都内嵌在了一个 HTML 文件里，换来的是真正的离线双击即用。

**想自己改内容重新打包？**
源码在 `web/` 目录（Vue 3 + Vite），书籍 markdown 原文在压缩包外的源目录中，构建命令见 `web/README.md`。
