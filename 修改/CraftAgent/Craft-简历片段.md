# ThreadCove · 个人研究 Agent 工作台

基于 Craft Agents 参考架构复现并实现的个人研究工作台，面向技术选型、公开资料阅读与方案比较，使用 TypeScript 将检索取材、受限任务委派和执行记录整合到 Electron/Web 界面。

- **研究工具接入与证据留存** 面向技术调研中实时取材与来源回看的需求，为 Pi 后端接入 web_search、web_fetch 与 MCP 代理工具；将检索结果、来源 URL 和抓取时间保存为会话产物，并对网页读取实施地址校验、重定向复检及响应上限，使取材过程可检查、来源可回看。

- **受限子 Agent 编排** 面向可独立调查的子问题，实现 delegate_research，以共享并发槽、父运行累计子任务数与网页工具调用预算、子任务模型轮数限制和叶子工具白名单约束 Pi 子代理；传播父任务取消和子任务超时，等待子任务清理并分别记录状态与来源，在常规子任务失败时保留成功分支结果。

- **Context Engineering** 针对 Claude 后端历史无界注入的问题，按字符预算提取近期 user/assistant/tool 文本、保留角色与时序，并以引用数据拼接当前问题，实现可供后续提问使用的有界历史桥接。

- **多后端适配与进程边界** 面向模型接口和运行方式差异，以 AgentBackend.chat() 统一 DeepSeek、Claude 与 Pi 的调用及生命周期接口；将 Pi SDK 置于 JSONL 子进程，工具请求代理回宿主执行，使已有后端按配置切换，同时保留各后端的能力边界。

- **任务生命周期与流式恢复** 针对重复提交、取消及断线后的状态歧义，通过 requestId/runId 区分受理与完成，统一消费 AgentEvent；以稳定消息 ID、累计文本快照和 JSONL 检查点保存文本及执行结果，向桌面/Web 提供一致事件入口，并在重启时将未完成任务标记为中断。
