# Clawtide · 自托管数字员工工作站

基于 HappyClaw 参考架构复现并实现的个人项目，以跨境电商运营为演示场景，将 IM 消息与定时任务接入 Agent 执行链，并提供 Profile 配置、工作区授权和 Web 管理入口。

**技术栈：** TypeScript、Node.js、Hono、SQLite、React、WebSocket、Claude Agent SDK。

- **任务物化与条件认领** 针对定时任务重复触发与执行记录难以追踪的问题，基于 SQLite 唯一键和条件更新，设计了 occurrence 物化、owner/token 认领及终态记录链路，实现了发生点去重与任务状态更新的条件校验。

- **Agent Profile 与配置变更** 针对数字员工规则散落、局部修改易覆盖其他配置的问题，基于四段式 Prompt 与版本快照，设计了独立字段更新、历史内容恢复和草稿短语确认入口，实现了配置分段维护与历史可回看。

- **IM 适配与会话接入** 针对不同 IM 消息格式和会话形态难以复用的问题，基于 ImChannelAdapter 与能力声明，设计了飞书、Telegram 适配及消息规范化链路，实现了渠道消息经挂载解析进入统一执行入口，其余渠道保留为骨架。

- **工作区授权与 IM 准入** 针对管理角色与资源归属混用的问题，基于所有者判定和发送者身份校验，设计了读、改、删独立授权函数与 audience_mode 准入分支，实现了管理员无所有权旁路、Home 禁删及拒绝分支不执行。

- **会话认证与登录限流** 针对 Web 管理入口的身份冒用与重复登录尝试，基于随机会话 token、HMAC 签名和进程内计数，设计了签名核验后查库、双名 Cookie 及两层限流，实现了失效会话拒绝与账号维度的尝试约束。
