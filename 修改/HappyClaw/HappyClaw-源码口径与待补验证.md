# Clawtide 源码口径与待补验证

> 固定提交：`dde300313de851baa953f24f6a0f8c75e9cacd3f`。以下是本轮源码核查发现的限制与建议验证，不是已修改代码或已运行通过的结果。证据E编号定位见 `evidence/源码导航.md`。
> 主张范围已经在简历中收窄，但实际代码问题仍然存在；不得把“改文案”当成“修好代码”。

## 1. 最优先补的四条实际链路

### V01 · 失租到执行器取消的链路

**现状：**`startHeartbeat`更新失败时停心跳并记录“aborting run”，但没有向executeRun传AbortSignal，也没有调用实际停止函数；SchedulerDeps.executeRun签名不含取消对象。[E02、E18]

**验证：**使用阻塞的可观察执行器启动run，改变数据库owner/token，使续租失败，再检查执行器是否仍继续工作，以及旧token能否写最终状态。分别记录“外部动作是否停止”和“DB状态更新是否被拒”，不能只看日志。

**建议修复方向：**运行级取消对象、下游调用取消传播、清理完成等待；必要的外部幂等键/栅栏。当前未实现，不在本轮修改。

### V02 · 完整pump与多进程恢复

**现状：**claim SQL有“running、租约过期、started_at为空”的接管分支，但candidates只选queued/retry_wait。recoverOnStart又把所有未启动running行释放，不检查旧实例是否仍活跃或租约是否到期。直接调用claimOne的测试不足以证明整个pump和多进程启动安全。[E01、E02、E13]

**验证：**从真实候选扫描驱动过期未启动行；用两个独立连接或进程，在A已认领未开始时启动B恢复流程，确认B是否释放A的有效租约。记录每个状态和token变化，不把同连接顺序调用当成并发压测。

**建议修复方向：**统一候选选择与可认领条件；启动恢复只处理确实失效的持有者/过期租约。当前不主张安全多活部署。

### V03 · 定时入口的Profile与权限装配

**现状：**`server.ts`中定时executeRun选择/创建Session后调用runtime.sendMessage，但未传Profile systemPrompt；Web onChat和IM入口另有Profile组装逻辑。当前三入口共享执行函数，不共享完整配置策略。[E07、E19]

**验证：**给Profile放入可观察的独特标记，用可注入TurnExecutor捕获Web、IM、定时三个入口实际传给SDK的options。比较systemPrompt、目标Session与执行身份；不要只读数据库Profile字段。

**建议修复方向：**将受信的Profile/工作区上下文解析复用给定时路径，并分别验证授权与默认规则。没有实际接线前不写“三入口行为一致”。

### V04 · 草稿发布失败与直接CRUD

**现状：**`confirmDraft`先设置confirmed再执行publish回调，JSON解析或Profile更新失败时可能留下已确认但未发布状态；普通POST/PATCH直接修改Profile，不经过草稿短语。草稿JSON由客户端提供，未看到该路径本身调用模型生成。[E04、E05]

**验证：**分别提交非法JSON、字段不合法或注入抛错的发布回调，检查草稿和Profile的状态；同时确认登录用户直接PATCH是否无需短语。将“人工草稿门”与“所有配置变更审批”分开。

**建议修复方向：**先验证，再用事务或可恢复状态机将发布与草稿状态同步；决定普通编辑与AI草稿各自策略。短语生成当前用Math.random，不应将其宣传成密码学安全授权令牌。

## 3. 三类验证不能混为一个“通过”

**确定性机制测试：**唯一键、claim条件、字段PATCH、Owner分支、签名/限流。这类测试能使用本地DB和执行器替身，不需要真实模型；它证明被测试的机制，不证明模型效果。

**业务整链联调：**用户输入→真正SDK调用→IM入站/回复或定时结果。需要真实凭据、目标权限和脱敏日志；README历史描述不是本轮复验。

**模型任务质量：**是否遗漏运营异常、是否虚构库存和订单信息、建议是否受限。需要固定样例、判定标准、重复运行和人工核查；不能把工程测试数量当准确率。

## 4. 建议运行记录格式

```json
{
  "case_id": "V01",
  "commit": "实际提交",
  "environment": "实际系统/运行时/数据库配置",
  "executor": "fixture 或真实 SDK/模型；两者分开",
  "command": "实际执行命令",
  "expected": "预期状态、外部动作和错误",
  "observed": null,
  "status": "not_run",
  "log_path": null,
  "limitations": []
}
```

这段只是记录模板。不要把null改成推测结果；不要提交模型密钥、Cookie或真实客户信息。
