## 2. 可贴简历版

项目名称：Craft Agents 高阶 Agent 架构与多端执行平台

- 针对多后端 Agent 执行逻辑耦合、替换成本高的问题，基于 AgentBackend 与统一事件抽象，设计了模型后端与执行编排的职责边界，实现了多运行时能力的可替换接入。
- 针对流式输出、工具调用和权限请求缺少统一生命周期的问题，基于 AgentEvent 状态机与进程外会话执行，设计了可恢复的事件传输路径，实现了多端渲染与错误恢复的统一。
- 针对 MCP、Skills 和 Sources 等外部能力接入分散的问题，基于 ServerBuilder、凭据注入和权限配置，设计了统一能力接入层，实现了外部能力配置与 Agent 调度边界的收敛。
- 针对多端 Agent 行为回归不可见的问题，基于事件流建模、Channel Map 契约和冒烟测试，设计了行为评测与契约验证机制，实现了回归问题的可定位。

## 3. 面试回写

- claim-craft-001：已验证；可以处理替代后端和失败恢复追问。
- claim-craft-002：部分验证；缺口是本人参与的具体进程边界。
- claim-craft-003：未覆盖；改问能力接入失败时的权限处理。
- claim-craft-004：已验证；变体题改问事件顺序变化下的回归定位。

若用户只能解释 AgentEvent 和契约测试，不足以继续使用高风险 R18，应将其降级为 R10/R24 组合。
